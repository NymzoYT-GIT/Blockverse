
# 🟦 BLOCKVERSE

[![Domain by devs.li](https://devs.li/badge.svg)](https://blockverse.devs.li)

### Discover. Play. Create.


Welcome to **Blockverse**, an ambitious browser-based gaming platform inspired by the creativity of sandbox gaming communities.

Blockverse aims to bring players and creators together through multiplayer games, customizable avatars, social features, virtual currencies, and an advanced game creation studio.

🌐 **Website:** https://blockverse.devs.li

---

## 🎮 Platform Features

### 🕹️ Gaming
- Browse and discover community-created games.
- Launch games directly from the browser.
- Multiplayer gaming support.
- Game ratings and favorites.
- Player profiles and statistics.

### 🧱 Creator Studio
- Advanced browser-based 3D editor.
- Build environments and maps.
- Create and customize objects.
- Animation tools.
- Scripting support.
- Publish games to the platform.

### 👤 Player Accounts
- Registration and login.
- Customizable player profiles.
- Avatars and cosmetics.
- Friends and social features.
- Player achievements.

### 💰 Virtual Economy
- Earnable virtual currency.
- Premium-style virtual currency.
- Virtual marketplace.
- Items, accessories, and cosmetics.

### 🤖 AI Features
- AI-powered player assistance.
- Creator assistance.
- Automated moderation support.
- Platform security monitoring.
- Economy anomaly detection.

### 🛡️ Safety and Moderation
- Reporting system.
- Moderation tools.
- Ban management.
- Community safety systems.
- Administrator dashboard.
